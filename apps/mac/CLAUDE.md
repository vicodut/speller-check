# macOS helper (Swift)

Status: not started (milestones 3–5). Don't scaffold anything here until asked.

## Role
Eyes and hands only: read the focused field via Accessibility, draw underlines, badge and card, write fixes back, launch and supervise the core binary.
No checking logic here. If you're about to make a decision about text, it belongs in the core.

## Stack
Swift, SwiftUI for the card and settings, AppKit panels for the overlay, MVVM. SwiftFormat + SwiftLint.
The Xcode project is generated by XcodeGen from `project.yml`; never edit `.xcodeproj` by hand.

## Layout
```
Sources/
  App/             entry point, menu bar, core process supervisor
  Features/
    Accessibility/ focused element, text, range bounds, write-back
    Overlay/       underline windows
    Badge/
    Card/          View + ViewModel
    Settings/      View + ViewModel, Keychain
  Shared/
  Protocol/        *.generated.swift from packages/protocol
```

## Conventions
- Views ≤ ~150 lines; extract subviews early.
- All AX calls go through `Features/Accessibility`.
- Never read `AXSecureTextField`. Check the app blocklist before reading anything.
- Sign with the fixed dev identity from `project.yml` so the Accessibility permission survives rebuilds.
